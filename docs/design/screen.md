# 画面設計

[仕様](../spec.md) と [データ設計](data.md) をもとにした画面設計です。MVP の範囲を対象にしています。画面遷移は [画面遷移図](screen-transition.md)、表示項目・操作・見た目の詳細は [画面詳細設計](screen-detail.md) を参照。

## 画面一覧（MVP）

| 画面 | URL | 内容 |
| --- | --- | --- |
| 問題一覧 | `/` | 問題のタイトルを並べる。クリックで問題画面へ |
| 問題画面 | `/questions/{id}` | 説明文・ER図・解答群を表示し、空欄を埋めて答え合わせする |
| ログイン | `/login` | ログインIDとパスワードでログインする |
| 新規登録 | `/signup` | ログインID・メールアドレス・パスワードを決めて登録する |
| スマホ向け案内 | （全画面共通） | 画面幅が 1024px 未満のとき、どの画面でも「PCで開いてください」とだけ表示する |

答え合わせの結果は問題画面の中に表示し、別画面には分けない。

ヘッダーの右端には、どの画面でもログイン状態を出す（ログイン・新規登録の画面を除く）。

```
+--------------------------------------------------+
| ER図クイズ                     [ログイン] [新規登録] |   未ログイン
| ER図クイズ                         taro [ログアウト] |   ログイン中
+--------------------------------------------------+
```

## ログイン・新規登録

```
+------------------------------+      +------------------------------+
| ログイン                      |      | 新規登録                      |
| ログインID [            ]     |      | ログインID [            ]     |
| パスワード [            ]     |      | メールアドレス [        ]     |
| [ログイン]                    |      | パスワード [            ]     |
| アカウントがない場合は 新規登録 |      | [登録する]                    |
+------------------------------+      | アカウントがある場合は ログイン |
                                      +------------------------------+
```

- ログイン・登録できたら、[ログイン] / [新規登録] を押した画面に戻る（`?next=` で覚えておく）。
- 失敗したら、フォームの下に赤い文字で理由を出す。

## 問題一覧

```
+--------------------------------------------------+
| ER図クイズ                                        |
+--------------------------------------------------+
| ECサイトの注文                     空欄 3   [解く] |
| 図書館の貸出                       空欄 5   [解く] |
| ...                                              |
+--------------------------------------------------+
```

- 1行に、タイトルと空欄の数を表示する。
- 難易度や★評価の列は、MVPの次で追加する。

## 問題画面（解答中）

説明文が上（折りたためる）、ER図が真ん中、解答群が下。

```
+--------------------------------------------------+
| ← 一覧へ   ECサイトの注文                          |
+--------------------------------------------------+
| ▼ 業務の説明文                        [小さくする] |
|   〇〇社では、会員が商品を注文する。…               |
|   （長い場合は枠の中でスクロール）                  |
+--------------------------------------------------+
|        ER図（IE記法、配置は固定）                  |
|   +--------+          +--------+                 |
|   | 会員   |──┼───○<──| [ ア ] |                 |
|   +--------+          +--------+                 |
|   | 会員番号|          | 注文番号|                 |
|   | [ イ ] |          | ...    |                 |
|   +--------+          +--------+                 |
+--------------------------------------------------+
| 解答群: [注文] [会員] [商品] [メールアドレス] ...    |
|                                  [答え合わせ]      |
+--------------------------------------------------+
```

- 説明文は画面上部の開閉できる枠に表示する。「小さくする」で見出しの1行だけになり、ER図を広く使える。
- 空欄には記号（ア、イ…）を表示し、解答群の選択肢をドラッグして置く。
- 置いた選択肢は、別の選択肢を上から置くと入れ替わる。空欄から外へドラッグすると外れる。
- 1つの選択肢は1つの空欄にしか置けない。置いた選択肢は解答群から消え、空欄から外れると解答群の元の位置に戻る。
- 空欄が残っていても答え合わせできる（未回答は不正解）。

## 問題画面（答え合わせ後）

```
+--------------------------------------------------+
| 3問中 2問正解                                      |
+--------------------------------------------------+
| ▶ 業務の説明文                                     |
+--------------------------------------------------+
|   +--------+          +-----------+              |
|   | 会員   |──┼───○<──| 注文 ☑️    |              |
|   +--------+          +-----------+              |
|   | 会員番号|                                     |
|   | 会員 ✖︎ 正解:メールアドレス |                       |
+--------------------------------------------------+
| 解説                                              |
| 「会員」と「注文」は1対多の関係で…                   |
|                     [もう一度解く] [一覧へ戻る]     |
+--------------------------------------------------+
```

- 空欄ごとに、正解なら ☑️、不正解なら ✖︎ を付ける。不正解の空欄には、その下に正解を小さく表示する。
- 解説文は、解答群があった画面下部の場所に表示する。
- 答え合わせ後は選択肢を動かせない。
- 「もう一度解く」で空欄を空にして解き直せる。解き直した結果も記録する。
