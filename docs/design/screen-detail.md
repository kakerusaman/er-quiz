# 画面詳細設計

[画面設計](screen.md) と [画面遷移図](screen-transition.md) をもとに、画面ごとの表示項目・操作・API・エラー時の動きをまとめたものです。見た目は、デザイン案（mockups/ の4枚）に合わせています。

## 共通

- 画面幅が 1024px 未満のときは、どの画面でも「PCで開いてください」だけを表示する。幅を広げると元の画面に戻る（入力中の解答は消えない）。
- API を待っている間は「読み込み中…」を表示する。
- 画面上部にアプリ名「ER図クイズ」を表示し、押すと問題一覧へ戻る（解答中は [← 一覧へ] と同じ確認を出す）。

## 1. 問題一覧（`/`）

### 表示項目

| 項目 | 内容 | 元データ |
| --- | --- | --- |
| 問題のタイトル | 例「ECサイトの注文」 | `title` |
| 空欄の数 | 例「空欄 3」 | `blankCount` |
| [解く] ボタン | 問題画面へ移る | `id` |

- 並び順は新しい問題が上（API の返す順のまま）。
- 問題が0件のときは「問題がまだありません」と表示する。

### 操作

| 操作 | 動き |
| --- | --- |
| [解く] を押す | `/questions/{id}` へ移る |

### API

- 表示時に `GET /api/questions`。

### エラー時

- 取得に失敗したら「読み込みエラー」を表示する。

## 2. 問題画面・解答中（`/questions/{id}`）

### 表示項目

| 領域 | 項目 | 内容 |
| --- | --- | --- |
| 上部 | [← 一覧へ]、タイトル | |
| 説明文 | 業務の説明文 | 開閉できる枠。最初は開いた状態。長い場合は枠の中でスクロール |
| ER図 | エンティティ | 見出し（エンティティ名）と属性の行。属性の左に「PK」「FK」「PK/FK」の小さなバッジを付ける |
| ER図 | リレーションシップ | IE記法の線。両端に多重度の記号（｜｜、○｜、｜と鳥の足、○と鳥の足） |
| ER図 | 空欄 | 記号（ア、イ…）を表示した枠。選択肢を置くとその文字列に変わる |
| 下部 | 解答群 | 空欄に置いていない選択肢を API の順に並べる |
| 下部 | [答え合わせ] ボタン | |

- ER図の配置は固定（エンティティはドラッグできない）。図全体の拡大・縮小（マウスホイール、＋／－ボタン）と、図をつかんで動かす操作はできる。

### 操作

| 操作 | 動き |
| --- | --- |
| 説明文の [小さくする] / [開く] | 説明文の枠をたたむ・開く |
| 解答群の選択肢を空欄へドラッグ | 空欄にその選択肢が入り、解答群から消える |
| 選択肢が入った空欄へ別の選択肢をドラッグ | 入れ替わる。解答群から置いたときは、外れた選択肢が解答群の元の位置に戻る |
| 空欄に入った選択肢を空欄の外へドラッグ | 空欄が空に戻り、選択肢が解答群の元の位置に戻る |
| [答え合わせ] | 回答を送り、答え合わせ後の状態になる。空欄が残っていても送れる |
| [← 一覧へ] | 空欄を1つでも埋めていたら「解答が消えますがよいですか？」と確認し、OKなら一覧へ。何も埋めていなければすぐ一覧へ |

- ドラッグ中の選択肢が「重なった空欄」は、カーソルの位置ではなく、選択肢のチップと空欄の枠が重なっているかで決める。2つの空欄に重なったときは重なりが大きいほう。落とすと、その空欄に入る。
- キーボード操作（Space でつかむ）では、一番近い空欄に重なっているとみなす。

### API

- 表示時に `GET /api/questions/{id}`。
- [答え合わせ] で `POST /api/questions/{id}/attempts`（空欄ID → 選択肢ID。未回答は送らない）。送信中はボタンを押せなくする。

### エラー時

- 問題が見つからない（404）、または取得に失敗したら「読み込みエラー」を表示する。
- 答え合わせの送信に失敗したら、解答はそのまま残し、「送信に失敗しました。もう一度お試しください」を表示する。

## 3. 問題画面・答え合わせ後（`/questions/{id}`）

### 表示項目

| 領域 | 項目 | 内容 |
| --- | --- | --- |
| 上部 | 点数 | 例「3問中 2問正解」 |
| 説明文 | 業務の説明文 | 解答中と同じ（開閉の状態も引き継ぐ） |
| ER図 | 空欄 | 置いた選択肢をチップで表示。正解なら緑のチップに ✓ アイコン、不正解なら赤のチップに ✕ アイコンを付け、チップの下に赤字で「正解: ○○」を表示。未回答は空のチップに ✕ |
| 下部 | 解説 | 解答群のあった場所に表示 |
| 下部 | [もう一度解く]、[一覧へ戻る] | |

### 操作

| 操作 | 動き |
| --- | --- |
| [もう一度解く] | 空欄をすべて空にし、解答中の状態に戻る。API は呼ばない |
| [一覧へ戻る] / [← 一覧へ] | 確認なしで一覧へ |
| 選択肢のドラッグ | できない |

## 4. 読み込みエラー

### 表示項目

- 「問題を読み込めませんでした」
- [一覧へ戻る] ボタン（一覧の取得に失敗した場合は [再読み込み]）

デザイン案: [スマホ向け案内](mockups/narrow.png)、[問題一覧](mockups/list.png)、[問題画面・解答中](mockups/question-solving.png)、[問題画面・答え合わせ後](mockups/question-result.png)

### レイアウト

- 上部に白いヘッダー（下に薄い境界線）。一覧ではアプリ名「ER図クイズ」、問題画面では「← 一覧へ」とタイトルを表示する。
- 本文は薄いグレーの背景の上に、白いカード（角丸、薄い枠線）を縦に並べる。本文の幅は約1120pxで、どの画面でも画面の中央に置く。
- 問題画面のカードは上から「点数（答え合わせ後のみ）」「業務の説明文」「ER図」「解答群 または 解説」。

### 部品

| 部品 | 見た目 |
| --- | --- |
| メインのボタン（解く、答え合わせ、一覧へ戻る） | 青の塗り、白い太字、角丸 |
| サブのボタン（もう一度解く） | 白地に青の枠と青の文字 |
| 空欄 | 破線の枠、薄いグレーの塗り、中に青い記号（ア、イ…） |
| 選択肢が重なった空欄 | ドラッグ中の選択肢のチップが空欄の枠に重なった時点で、青い枠と薄い青の塗りに変わり、少し（1.1倍）大きくなる。離れると元の大きさに戻る |
| 解答群の選択肢 | 白地に枠線のチップ。解答群の見出しの横に「選択肢を空欄にドラッグして置きます。置いた選択肢は解答群から消え、空欄から外すと戻ります。」 |
| PK / FK バッジ | 小さな枠付きの文字 |
| 説明文の開閉 | 見出しの左に ▼ / ▶、右端に「小さくする」/「広げる」のリンク |
| スマホ向け案内 | 背景の中央に太字で「PCで開いてください」だけ |
| ER図の拡大・縮小ボタン | デザイン案にないため、ER図カードの右下に小さな ＋ / － ボタンを置く |
